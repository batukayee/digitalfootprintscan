How to Remove Yourself From MyLife (2026 Opt-Out Guide)

MyLife provides a privacy-request workflow for removing or suppressing a reputation profile.

By Digital Footprint ScanUpdated September 14, 2026
TL;DR

Find your profile, open the current privacy request route, provide the requested details, verify your email, submit, and recheck.

Run a free digital footprint scan to see what else is exposed.

MyLife profiles can contain names, locations, age information, contact details and other information from public and commercial sources.

How to remove yourself from MyLife

1Find your profile

Search MyLife for your name and location and identify the profile that belongs to you.

2Open the privacy request route

Use MyLife's current privacy or FAQ workflow for requesting Reputation Profile removal.

3Provide identifying details

Enter the name, location and other matching information requested by the current form.

4Verify and submit

Complete email verification and any security checks, then submit the request.

5Recheck the profile

Search again after processing and keep your confirmation details.

Important: MyLife profile removal does not erase the underlying public records or remove the same data from other services.

How to verify removal

Repeat the same search after processing and check the old profile URL if you saved it.

Why information can return

Data sources change and databases refresh. A later update can create a new or changed profile.

Frequently asked questions

Is MyLife removal free?

The self-service privacy request can be submitted without purchasing a removal subscription.

Can a profile return?

Yes. Refreshed source data can result in a new profile.
