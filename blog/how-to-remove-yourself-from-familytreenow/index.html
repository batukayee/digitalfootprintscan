How to Remove Yourself From FamilyTreeNow (2026 Opt-Out Guide)

FamilyTreeNow publishes genealogy and public-record information about people and relatives. Its opt-out process is free and can be completed online.

By Digital Footprint Scan · Updated September 14, 2026

TL;DR

Find your FamilyTreeNow profile, open the official opt-out page, submit the matching record, complete any verification, and recheck after processing.

👁 Run a free digital footprint scan to see what else is exposed →

FamilyTreeNow can connect names with addresses, relatives, age information and other public-record or genealogy data. FamilyTreeNow is separate from FamilySearch.

How to remove yourself from FamilyTreeNow

1Find your matching profile

Search FamilyTreeNow for your name and use location details to narrow the results. Review the profile carefully before submitting an opt-out.

2Open the official opt-out page

Go to FamilyTreeNow’s opt-out page.

3Identify the record

Follow the current on-page instructions to identify the profile you want suppressed.

4Complete verification

If FamilyTreeNow asks you to confirm the request or complete a security step, finish it before leaving the page.

5Submit the request

Confirm the removal request and keep any confirmation information shown.

6Verify later

Search FamilyTreeNow again after processing. Public-record sources can change, so recheck periodically if information returns.

Important: An opt-out suppresses a listing on FamilyTreeNow; it does not erase the underlying public records or remove the same information from other services.

How to verify removal

Repeat the same name and location search you used originally. Compare the results carefully and keep any confirmation of the request.

Why information can return

People-search and genealogy databases can refresh from changing public records. A later update can create a new profile or restore information.

Frequently asked questions

Is FamilyTreeNow opt-out free?

Yes, the self-service opt-out is intended to be free.

Is FamilyTreeNow the same as FamilySearch?

No. They are separate services and are not affiliated.

Will opting out remove public records?

No. It affects the FamilyTreeNow listing, not the underlying source records.
